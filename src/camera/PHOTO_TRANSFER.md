# 상모 촬영과 일회성 QR

- 마치기 화면의 사진 버튼 → /photo. 카메라는 기존 CameraProvider를 재사용합니다.
- MediaPipe의 기존 로컬 Pose 모델로 귀 위치를 추적합니다. 머리 위치는 보간하며,
  고개 움직임에 따라 상모 끈이 회전합니다. 고깔로 바꿀 수 있습니다.
- 미리보기와 촬영은 동일한 canvas를 사용합니다. JPEG는 React 메모리와
  object URL에만 존재하며, 다시 찍기/페이지 종료 시 URL과 연결을 해제합니다.
- 사용자가 QR 버튼을 눌렀을 때만 PeerJS 연결을 생성합니다.
  PeerJS 공개 PeerServer는 연결 메타데이터를 교환하며 사진을 저장하지 않습니다.
  사진 바이트는 WebRTC DataChannel로 전달합니다. Google STUN을 사용합니다.
- QR에는 사이트 루트 주소와 fragment의 랜덤 peer ID/일회성 토큰이 들어갑니다.
  루트에서 수신 경로로 이동하므로 정적 배포의 직접 경로 404를 피합니다.
- QR은 5분 후 만료되고 첫 인증된 연결만 허용합니다. 수신 확인 후 종료합니다.
  연결 실패 후에는 QR 닫기 → 다시 만들기로 재시도합니다.
- 촬영 브라우저가 열려 있어야 합니다. localhost QR은 휴대폰에서 접속할 수 없으므로
  실제 사용은 공개 HTTPS 배포 주소에서 진행해야 합니다.
- 서버에 사진을 보관하지 않지만 완전히 외부 서버가 없는 방식은 아닙니다.
  STUN으로 직접 연결할 수 없는 네트워크에서는 실패 안내와 로컬 다운로드를 제공합니다.
  모든 모바일/기관 네트워크 지원에는 인증된 TURN 중계 추가가 필요합니다.

## 2026-10 연결 보완
- STUN 전용 설정을 제거하고 설치된 PeerJS의 기본 STUN + TURN 구성을 사용합니다.
- 연결 서버 오류, 상대 브라우저 없음, 전송 시간 초과를 구분해서 표시합니다.
- 기본 공개 TURN의 가용성은 보장되지 않습니다. 중계 후보가 나오지 않는 환경에서는
  별도의 인증된 TURN 또는 HTTPS 임시 사진 저장 방식이 필요합니다.
- 코드 수정은 로컬 작업이며 배포본은 새 배포 이후에 반영됩니다.
